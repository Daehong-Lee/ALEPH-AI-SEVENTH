PLAN → DO

계획

할 일은 별도 탭에서 만들지 않습니다. 계획을 입력할 때 계획의 하위 항목으로 함께 등록합니다.

할 일

완료 버튼을 누르면 해당 항목이 계획의 진행 중 목록에서 완료 목록으로 이동하고, 완료 날짜가 실행 기록에 자동으로 남습니다.

DONE

완료

계획 또는 할 일을 완료한 순서대로 표시합니다. 완료된 항목은 이 화면에서 수정하거나 되돌릴 수 없습니다.

DO → SEE

보안 점검 메모

  • 브라우저에는 Supabase URL과 anon/publishable key만 둡니다.
  • service_role/secret key는 넣지 않습니다.
  • 비밀번호는 Supabase Auth가 처리하고 앱 테이블에는 저장하지 않습니다.
  • RLS가 사용자별 자료 접근을 제한합니다.
